# M-11: i18n — Telugu/Hindi Switch, Mobile/Responsive

## Roles
- Tester roles: all

## Pre-requisites
- [ ] Logged in as PM
- [ ] At least one project with data
- [ ] Browser: Chrome incognito (desktop first, then mobile DevTools)

## Steps

| # | Action | Expected Result | Pass/Fail | Notes |
|---|--------|----------------|-----------|-------|
| 1 | Navigate to any page. Find language switcher (globe icon or dropdown) | Language switcher visible in header/sidebar: English (EN) / తెలుగు (TE) / हिन्दी (HI) | | |
| 2 | Switch to తెలుగు (Telugu) | Page reloads. All UI strings in Telugu. Labels, buttons, nav items, table headers translated | | |
| 3 | Navigate to a project → Issues tab | Issue titles (user-generated) remain in English. UI chrome (headers, buttons) in Telugu | | |
| 4 | Create a new issue with Telugu text in the description | Issue saved. Telugu text displays correctly (no garbled characters) | | |
| 5 | Switch to हिन्दी (Hindi) | Page reloads. All UI chrome in Hindi | | |
| 6 | Switch back to English | Page reverts to English | | |
| 7 | Refresh the page | Language preference persisted (localStorage or cookie). Still showing English | | |
| 8 | Open DevTools → Toggle Device Toolbar (Ctrl+Shift+M). Select iPhone 14 / Pixel 7 | Responsive layout activates. Sidebar collapses to hamburger menu | | |
| 9 | Navigate through tabs: Projects → project detail → Issues | All pages render correctly at 390×844. No horizontal scroll. Text not cut off | | |
| 10 | Switch to Telugu while in mobile view | UI chrome in Telugu, layout still responsive. No overlapping elements | | |
| 11 | Tap "New Issue" (mobile) | Form opens in full-screen or bottom sheet. Easy to tap fields | | |
| 12 | Rotate to landscape | Layout reflows. Elements not hidden or truncated | | |
