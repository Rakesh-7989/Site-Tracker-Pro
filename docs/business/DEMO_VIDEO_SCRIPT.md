# SiteTrack Pro — 3-Minute Demo Video Script

**Target length:** 2:55 — 3:05
**Audience:** Indian builder firm owner (orgadmin) deciding whether to switch from spreadsheets / Powerplay / BuildSupply.
**Language:** Telugu narration with English subtitles. (Re-record in Hindi for North India later.)
**Tone:** Calm, confident, editorial — match the brand. No "AMAZING!!!" caps-lock energy.

---

## Pre-production checklist

- [ ] Demo data loaded (Load demo data button on login → BuildCo India org)
- [ ] Browser at 1440×900, screen recorder set to 30fps, dark mode OFF
- [ ] Microphone: Shure SM7B or similar — no echo, no fan noise
- [ ] Narrator: native Telugu speaker, can pronounce English construction terms cleanly
- [ ] Editor: Final Cut / DaVinci Resolve. Captions exported as SRT + burned-in
- [ ] Music: subtle ambient strings, royalty-free (Epidemic Sound / Artlist), under -18 dB
- [ ] Total file size: <80MB for WhatsApp shareability

---

## Scene-by-scene shot list
