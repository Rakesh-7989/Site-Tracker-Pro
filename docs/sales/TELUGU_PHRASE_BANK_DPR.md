# Telugu Phrase Bank — DPR Voice Note + Captions
*Sprint 1, Day 2 · Session 30.2*

The supervisor talent will speak these EXACT Telugu sentences during
the Loom shoot. Below each line: English gloss + a romanized
pronunciation hint for non-native QA + a backup variant if the talent
trips on the formal phrasing. Captions in the final Loom must match
the English gloss verbatim — no embellishment.

If the talent prefers a different dialect (Telangana Telugu vs Andhra
Telugu), use the variant marked **TS** (Telangana) — that's the
Hyderabad-builder default.

## How to use this file

1. Print page 1 (the script).
2. Read it aloud to the talent BEFORE rolling. Have them repeat it
   back. Correct pronunciation in private — never on camera.
3. Captions for the final Loom: copy the English-gloss column
   verbatim. No translation paraphrasing.

## Pronunciation rules for the supervisor talent

- **Long vowels** matter. "naynu" ≠ "nenu" — slight stretch on the
  first syllable. Don't crunch.
- **Aspirated consonants**: in "pour" (English loan word), preserve
  the English aspiration; don't Indianise to "pawar".
- **English loan words**: keep them English. Construction Telugu
  ALWAYS mixes English nouns (slab, basement, concrete, cubic
  metres, photo, geotag, send, pour). Don't try to Telugu-ize.
- **"Vasavi Vista"** is the demo project name. Pronounce as in
  English — don't add Telugu inflection.
- **Numerical**: "eighty" said in English, not "enabhai" — matches
  Hyderabad site-floor reality.

## Founder voiceover (beats 6–9, 30–60 sec)

Founder reads these in **Telugu-transliterated English with crisp
diction**. Apartment-cupboard recording booth (clothes absorb echo).
Two takes minimum; pick the one with the cleanest "p" / "t" / "s"
consonants.

### Beat 6 (30–38 sec) — promoter receives

> "Promoter ki WhatsApp lo coffee time ki message vasthondi —
> transcription, photo, geotag automatic ga vasthayi."

**Caption (English)**: "The promoter receives the message on WhatsApp at coffee time — transcription, photo, and geotag arrive automatically."

### Beat 7 (38–46 sec) — BuildNow Telangana badge

> "BuildNow Telangana audit trail tho anchor cheyabaduthondi —
> state govt validated."

**Caption (English)**: "Anchored to the BuildNow Telangana audit trail — state government validated."

## Captioning specification

- Font: **Inter Bold 28pt**, white #FFFFFF.
- Background: semi-transparent black (#000000, 70% opacity), 8px
  padding, 4px corner radius.
- Position: lower third, 80px above the bottom edge.
- Line wrap: max 2 lines, max 50 chars per line. If a line exceeds,
  cut a clause not a word.
- Caption appears 0.2 sec before audio starts; exits 0.5 sec after
  audio ends. No fade.
- Caption color shift for emphasis: when a number appears (₹29,999,
  ₹49,999, 30%), highlight that token in safety-orange #FF6B1A.
