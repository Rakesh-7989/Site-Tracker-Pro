— FAQ

Questions we hear often

Everything you need to know about how SiteTrack works for Indian builders.

How is "per org" different from "per seat"?

Powerplay charges ₹71,999/yr for 15–20 users. We charge ₹49,999/yr for ≤ 25 users. Add your site supervisor without paying extra. Pricing scales with project depth, not headcount.

Why "Hyderabad-first"?

Powerplay's public case studies (verified June 2026) feature zero Hyderabad marquee builders. The founder lives in Banjara Hills. The window to plant a flag with My Home / Aparna / Sumadhura / Vasavi / Lansum is closing — we're using it.

How does the BuildNow Telangana integration work?

BuildNow Telangana (Feb 2025) is the state's unified approval portal — it uses blockchain audit trails + WhatsApp-first status updates as core features. We mirror project metadata + display state-government-verified badges on every DPR. Real integration ships Sprint 2.

Does the RERA auto-filing actually work today?

Not yet. Today's RERA modules are scaffolds — they validate format but don't file. Real Telangana RERA quarterly filing ships in Sprint 4 (Day 46–60). Karnataka + Maharashtra in Sprint 5. We hide the scaffolds from non-staff users until the real flow ships — see docs/planning/FEATURE_FREEZE.md.

Is the data really mine?

Yes. Postgres Row Level Security enforces tenant isolation. Export any project as CSV, drawings as ZIP, RA bills as PDF — anytime. Termination delivers a full data-export zip + destruction certificate within 30 days.

What about WhatsApp + Telugu voice?

WhatsApp Business Cloud API is wired today. Sprint 2 ships the production-grade DPR composer with Telugu voice transcription (Bhashini API primary, AWS Transcribe fallback), photo + geotag capture, and BuildNow audit anchor on every send.
